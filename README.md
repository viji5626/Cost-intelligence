# Plant Cost Intelligence

A platform for cost intelligence, analysis, and optimization.

## Directory Structure

```text
hero-cost-intelligence/
├── .agent/          # Agent configuration and workflows
├── docs/            # Project documentation and specifications
├── frontend/        # Frontend user interface
├── backend/         # Backend API and server logic
├── ai/              # AI models, prompts, and inference pipelines
├── retrieval/       # Retrieval-augmented generation (RAG) and search indexers
├── calculations/    # Cost calculation engines and algorithms
├── data/            # Datasets, schemas, and processing scripts
├── database/        # Database migrations, models, and queries
├── evaluation/      # Evaluation benchmarks and accuracy tests
├── runtime/         # Execution environments and orchestration
├── tests/           # Integration and unit tests
├── docker/          # Dockerfiles and container configurations
└── README.md        # Project overview
```
